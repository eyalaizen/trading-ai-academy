# EA Academy 9.0 — קורס מקצועי ללימוד שוק ההון

## מה כלול
- **18 שבועות, 54 שיעורים מקוריים בעברית**: שני שיעורי מסחר/השקעות ועוד שיעור AI/מחקר בשבוע.
- לכל שיעור: מטרות, הסבר עקרוני, מנגנון עבודה, דוגמה מספרית, מגבלות, משימת מחקר, שאלת הבנה עם משוב וקישורים למקורות רלוונטיים.
- סביבת למידה של 70% עיון והבנה + 30% יישום; גרף ומחברת נפתחים לצד השיעור.
- שמירת מחברת והתקדמות בדפדפן באמצעות localStorage; ייצוא מחברת TXT.
- כל קובצי האתר המלאים כלולים. דף הלמידה הראשי: `academy-pro.html`. דף המעבדה: `index.html`.
- תוכן הקורס הגולמי נגיש ב־`course-content.json` ומוטען דרך `course-data.js`.

## פרסום ב-GitHub Pages
חלץ את קובץ ה-ZIP והעלה את **כל הקבצים** ל-root של המאגר (לצד `index.html`), ולא את ה-ZIP עצמו. לאחר commit ופרסום, פתח `https://eyalaizen.github.io/trading-ai-academy/academy-pro.html?v=9`.

## מגבלות חשובות
- זו תוכנית למידה מקורית, לא קורס או הסמכה רשמית של CMT/CFA/MIT/Yale.
- **54 שיעורים כוללים תוכן מקורי, דוגמאות ומשימות**, אך הם אינם כוללים הרצאות מוקלטות מקוריות ארוכות; לכל שיעור מקורות חיצוניים להעמקה.
- החלוקה 45 דקות לשיעור היא מסגרת עבודה מוצעת ולא אורך וידאו אוטומטי.
- הגרף המקומי מציג נתונים סינתטיים עד לטעינת CSV. הנתונים החיצוניים מ-TradingView עשויים להיות מושהים לפי הספק והבורסה; אין חיבור Live מובטח לכלים.
- Backtesting במעבדה הנוכחית נשאר הדגמתי. התוכן מיועד ללימוד ולא מהווה ייעוץ השקעות.
- אין שרת ואין חשבון משתמש; שמירת נתוני הלמידה היא מקומית בלבד.

## בדיקות
הקובץ כולל HTML, CSS, JS נפרדים; ניתן לבדוק במחשב באמצעות שרת מקומי. שימוש בספריות חיצוניות לא נדרש למסך הקורס עצמו.
