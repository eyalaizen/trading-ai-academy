# EA Academy 11.1 — חבילה מלאה להתקנה

**הגרסה הזו מכילה את כל 31 קובצי EA Academy 11.0, בתוספת קובץ זיהוי גרסה (`ea-academy-version.json`) ועמוד בדיקת פרסום (`version-check.html`).**

## מה נמצא בפנים
- **54 שיעורים / 18 שבועות:** שני שיעורי שוק ההון ושיעור AI בכל שבוע.
- **הסברים ולמידה (70%):** הרחבות גרסה 10 בכל 54 השיעורים, עם הסברי יסוד, מקורות, צעדי עבודה ודיון במגבלות.
- **18 שיעורי AI מורחבים:** קובצי `course-v11-data.js`, `course-v11.js`, `course-v11.css` מכילים חומרי עומק ייעודיים ל-AI בשוק ההון: LLM, ML, RAG, חילוץ נתונים מדוחות, בדיקות מודלים, הטיות ובקרת סיכונים.
- **36 שיעורי שוק ההון:** הרחבות קצרות מותאמות נושא בנוסף לגרסה 10.
- **סביבת עבודה:** גרף, מחברת, תרגול, מבחן, מקורות, מעקב התקדמות וכלי מסחר קיימים.

הגרסה אינה כוללת חיבור למודל AI חי או ספק נתוני שוק בזמן אמת בכל הכלים. התכנים מבוססים על חומר מקורי ללמידה ומקורות חיצוניים, ואין בכך הבטחת תשואה.

## התקנה — חשוב לא לדלג
1. חלץ את קובץ ה-ZIP למחשב. **בתוכו קבצים ישירות, בלי תיקיית עטיפה.**
2. פתח https://github.com/eyalaizen/trading-ai-academy על ענף `main`.
3. לחץ **Add file → Upload files** ובחר את **כל הקבצים** שחולצו (לא ZIP ולא תיקייה עליונה).
4. ודא שגם `course-v11-data.js`, `course-v11.js`, `course-v11.css`, `ea-academy-version.json`, `version-check.html` מופיעים ברשימת הקבצים להעלאה.
5. לחץ **Commit changes**.
6. בדוק את הכתובת:
   https://eyalaizen.github.io/trading-ai-academy/version-check.html?v=111
7. אם כל הקבצים מסומנים ✓, פתח:
   https://eyalaizen.github.io/trading-ai-academy/academy-pro.html?v=111

## איך לוודא שזה באמת העדכון האחרון
- בראש הקורס מופיע הכיתוב **גרסה 11.1**.
- ברשימת השיעורים יש כפתור **מסלול AI · 18**.
- בשיעורי AI, למשל שבוע 1 / שיעור 3, יש אזור העמקה הכולל הסבר, דוגמה, מתודולוגיה ומקורות.
- אם אתה עדיין רואה עיצוב ישן, נסה `Ctrl+Shift+R` לאחר שעמוד `version-check.html` עבר בהצלחה.

## בדיקות טכניות
בוצעו בדיקת תחביר לקובצי JavaScript, בדיקת שלמות ZIP, ובדיקת נוכחות קובצי לימוד ומספר השיעורים. בדיקות browser יופיעו בנפרד אם יבוצעו בהצלחה. הבדיקה `version-check.html` מאמתת נוכחות וגרסת manifest באתר הציבורי, לא את פעילות כל הכפתורים.
