# EA Academy 10.0 — קורס משולב: עיון, מחקר ויישום

גרסה זו מבוססת על EA Academy 9.0 ומכילה את **כל קובצי האתר**, כדי שאפשר יהיה להעלות אותם ישירות ל-GitHub Pages.

## מה התעדכן

- **54 שיעורים עם הרחבה ייעודית** של החלק העיוני בכל נושא, ולא רק העברה של קישורים ללשונית אחרת.
- לשונית **„שיעור מעמיק (70%)”** משלבת: מטרות, הסבר יסוד, העמקה נושאית, מנגנון, סקירת מחקר/מומחה בעברית, קישור למקור מרכזי, שאלת קריאה ממוקדת, שלושה צעדי יישום מודרכים, דוגמה מספרית ומגבלות ההסקה.
- לשונית **„מומחים ומחקרים”** מציגה את המחקר המרכזי שכבר נדון בשיעור ומקורות משלימים, עם שאלת מיקוד הקשורה בדיוק לתוכן שנלמד. התכנים ניתנים לסקירה בדפדפן ומפנים למקור המקורי באתרו.
- לשונית **„תרגול ומבחן (30%)”** נשמרה; גם מחברת השיעור, טעינת הגרף לצד הלמידה, מעקב ההתקדמות והכלים באתר נשמרו.
- נוסף מקור מקצועי לכלים טכניים: מדריך Fidelity; ולרצועות Bollinger: האתר הרשמי של John Bollinger. שני אלה מסומנים כ**מקורות מקצועיים**, לא כמחקר אקדמי שעבר ביקורת עמיתים.
- סך המסלול עדיין **18 שבועות / 54 שיעורים**. משך השיעור 45 דקות הוא תכנון למידה מוצע (31.5 דקות עיון + 13.5 דקות תרגול), וכולל קריאה/צפייה בהפניות חיצוניות, לא 31.5 דקות של וידאו המובנה באתר.

## פרסום

1. חלץ את ה-ZIP, בחר **את כל הקבצים שבתוכו**, והעלה אותם לראש המאגר הקיים `eyalaizen/trading-ai-academy` — לצד `index.html`.
2. לחץ Commit changes. אין צורך לשנות את הגדרות GitHub Pages.
3. פתח `https://eyalaizen.github.io/trading-ai-academy/academy-pro.html?v=10` והקש Ctrl+Shift+R במידת הצורך.

## קובצי תוכן מרכזיים

- `academy-pro.html` — מסך הקורס.
- `course-content.json`, `course-data.js` — 54 השיעורים המקוריים ותוכן העיון הבסיסי.
- `course-enrichment.json`, `course-enrichment.js` — **54 ההרחבות החדשות**, אחת לכל שיעור; הקובץ הגולמי ניתן לעריכה ידנית.
- `course-v10.js`, `course-v10.css` — ממשק ההצגה החדש.
- יתר הקבצים — מעבדת הגרפים והכלים הקיימים, ללא שינוי מהגרסה הקודמת למעט נתוני המקורות החדשים.

## אמינות ומגבלות

התוכן הוא עיבוד לימודי מקורי בעברית — **לא ציטוט מילולי של המרצים** ולא קורס מטעמם. הראיות מוגבלות בהתאם לשיטה ולתקופת המחקר: Lo–Mamaysky–Wang (2000) עסק בזיהוי שיטתי של תבניות; Brock–Lakonishok–LeBaron (1992) בדק כללי ממוצעים ופריצות במדגם היסטורי; Sullivan–Timmermann–White (1999) ניתח הטיית בחירת כללי מסחר. מקורות אחרים משמשים **רקע תיאורטי** או **הסבר מקצועי**, ולא הוכחת ביצועים.

האתר אינו מחובר באופן אחיד לנתוני Live. המעבדה המקומית מציגה נתונים סינתטיים עד לייבוא CSV; גם גרף חיצוני עשוי להיות מושהה. המחברת וההתקדמות נשמרות ב-localStorage בדפדפן בלבד. התוכן אינו ייעוץ השקעות.

- בדיקה בדפדפן מבודד עם הזרקת תוכן מקומי: מעבר לשיעור הבא, קישור בין לשוניות, פתיחת מקור, הופעת חלון הגרף, כתיבה במחברת, וצילום מסך בפריסת מחשב ונייד. **הבדיקה אינה מאמתת זמינות של אתרים חיצוניים או פרסום חי ב-GitHub Pages.**
