# EA Academy v7 — Learning Studio

גרסה זו מוסיפה סביבת למידה עצמאית `academy-pro.html` לצד האתר הקיים.

## מה קיים בפועל
- 6 שיעורי עומק מקוריים בעברית עם מטרות, הסבר, מקרה בוחן, משימת מחקר, שאלות פתוחות ומחוון.
- גרף מקומי משובץ באמצעות `index.html?embed=lab`, מחברת מקומית לכל שיעור, שמירה אוטומטית וייצוא TXT.
- תוכנית 48 שיעורים נוספים מסומנת במפורש כמתוכננת ולא כתוכן גמור.
- קישור ממרכז תוכנית הלימודים הקיים לסביבה החדשה.

## התקנה
העלה את כל הקבצים מתיקיית ה-ZIP לשורש GitHub repository. פתח `academy-pro.html` או את הקישור מתוך תוכנית הלימודים.

## מגבלות
אין נתוני שוק בזמן אמת מובטחים. הגרף המקומי סינתטי עד ייבוא CSV. השמירה היא בדפדפן בלבד. הקורס אינו שייך ל-CMT או CFA. יש לבצע בדיקת דפדפן לפני שימוש נרחב.
